# Sample Data

This folder contains a reduced sample of the processed datasets used in the project.

The full cleaned datasets are not included in the public portfolio version to keep the repository lightweight and avoid publishing the complete source data.  
The sample keeps the main structure of the project data and can be used to review the data model and run partial checks.

Sample logic:
- all paid deals are included;
- a stratified sample of non-paid deals is added;
- related contacts and calls are included where contact IDs are available;
- spend data is sampled by sources and campaigns present in the deals sample.
